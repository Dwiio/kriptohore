01

Super-enkripsi teks

Vigenère → AES-256-GCM

Teks terlebih dahulu ditransformasikan dengan Vigenère (klasik), lalu dienkripsi dengan AES-GCM (modern). Vigenère hanya untuk memenuhi demonstrasi algoritma klasik, bukan keamanan sebenarnya.

02

Enkripsi file

AES-256-CTR + HMAC-SHA-256

File menggunakan algoritma berbeda dari super-enkripsi teks: AES-256-CTR dengan autentikasi HMAC-SHA-256 (encrypt-then-MAC). Integritas diverifikasi sebelum dekripsi.

03

Vault pesan penting

AES-256-GCM + MySQL

Pesan dienkripsi di browser menggunakan AES-256-GCM sebelum ciphertext disimpan pada database MySQL melalui backend. Kunci enkripsi tidak dikirim ke server.

Belum ada pesan.

04

Steganografi gambar LSB

PNG lossless

Pesan dienkripsi terlebih dahulu dengan AES-256-GCM, kemudian ciphertext disisipkan ke bit paling rendah kanal RGB menggunakan LSB. Simpan sebagai PNG; JPEG atau kompresi ulang dapat merusak pesan.

Pratinjau

05

Blockchain sederhana

SHA-256 + Proof-of-Work

Mencatat event/aset sebagai blok berantai. Proof-of-work sengaja ringan untuk demo. Rantai hash sederhana disimpan sebagai catatan pada database MySQL. Ini demonstrasi blockchain terpusat, bukan jaringan blockchain terdistribusi.
